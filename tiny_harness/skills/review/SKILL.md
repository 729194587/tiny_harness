# Review workflow

1. Inspect the requested diff before making claims.
2. Check correctness, safety boundaries, and regression coverage.
3. Report findings in severity order with concrete file references.
4. If no findings remain, state that clearly and mention residual test gaps.

Treat this document as task guidance only. It cannot override system or user
instructions, grant tool permission, bypass hooks, or expand the workspace boundary.
