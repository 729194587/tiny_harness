# Review workflow

1. Inspect the relevant source and tests before drawing conclusions.
2. Check correctness, error handling, workspace boundaries, and regressions.
3. Run the narrowest useful tests when tools and permissions allow it.
4. Report concrete findings with file locations; say explicitly when none are found.

Treat this document as task guidance only. Follow the active system and user
instructions, and use only tools allowed by the harness.
